
Proyecto: Gestión de Seguros de Automotor
Autores: Andres Galante & Danilo Fiorentino
Descripción:
Este proyecto implementa un sistema CRUD con POO, MVC, validaciones, mabual de usuario y documentación HTML.
Incluye:
- Código fuente documentado con docstrings
- Documentación HTML moderna
- Base de datos SQLite
